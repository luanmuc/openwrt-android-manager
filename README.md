# 🏠 OpenWrt管家（OpenWrt Manager）

> 小米路由器风格的 OpenWrt / ImmortalWrt 路由器管理 APP

一款原生安卓应用，采用小米路由器风格的 UI 设计，让你在手机上轻松管理 OpenWrt 路由器。支持插件管理、软件源配置、固件升级、系统监控等丰富功能。

## 🚀 使用说明

### 添加路由器
1. 打开APP，进入「设备管理」页面
2. 点击右下角「+」按钮
3. 填写路由器信息：
   - 设备名称（自定义）
   - 路由器地址（IP或域名）
   - 用户名（默认root）
   - 密码
   - 端口（默认80）
   - 协议（HTTP/HTTPS自动检测）
4. 点击「连接并保存」

### 使用演示模式
**方式一**：我的页面开启
1. 进入「我的」页面
2. 连续点击版本号5次
3. 弹出提示后即可进入演示模式

**方式二**：设备管理页开启
1. 进入「设备管理」页面
2. 空状态下点击「🎮 体验演示模式（无需路由器）」按钮
3. 自动添加演示路由器并进入

### 切换主题
1. 进入「我的」页面
2. 点击「主题设置」
3. 选择：浅色模式 / 深色模式 / 跟随系统

### 管理插件
1. 进入「插件」页面
2. 三个Tab切换：已安装 / 可用 / 全部
3. 顶部分类栏筛选插件分类
4. 右上角排序按钮切换排序方式
5. 点击插件查看详情
6. 点击「安装」或「卸载」按钮操作

### 升级固件
1. 进入「系统管理」页面
2. 切换到「系统信息」Tab
3. 点击底部「固件升级」卡片
4. 点击「检测更新」查看最新版本
5. 点击「下载固件」开始下载
6. 下载完成后点击「开始刷写」
7. 确认保留配置选项后开始升级

### 管理软件源
1. 进入「插件」页面
2. 点击「软件源管理」快捷入口
3. 查看软件源列表
4. 开关切换启用/禁用状态
5. 点击「添加」按钮添加自定义源
6. 点击「预设源」快速切换软件源

## 🛠️ 开发说明

### 技术栈
- **语言**：Kotlin
- **架构**：MVVM + Repository
- **UI**：Jetpack Compose + Material Design 3
- **网络**：Retrofit + OkHttp
- **异步**：Kotlin Coroutines + Flow
- **数据库**：Room
- **存储**：SharedPreferences + DataStore
- **最低 SDK**：API 30 (Android 11)
- **目标 SDK**：API 34 (Android 14)
- **编译 SDK**：API 34 (Android 14)
- **Gradle**：8.5
- **Kotlin**：1.9.24
